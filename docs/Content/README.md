# ANTWIN Content / Raw Data Directory

This directory stores source-derived content, normalized reference data, and prototype seed data.

## Rules

1. Never place unverified values into the reference dataset.
2. Keep source URL/title/date with every source-backed dataset.
3. Mark every record as LIVE, REFERENCE, SIMULATED or DERIVED.
4. Historical values must have temporal_status=HISTORICAL.
5. Planned Maitri-II values must have temporal_status=PLANNED.
6. Do not mix current Maitri with Maitri-II.
7. Do not claim private NCPOR SCADA/BMS data.
8. Synthetic telemetry must be generated by the simulator and remain reproducible.

Suggested files:
- sources.json
- station_reference.json
- simulation_parameters.json
- dependency_graph.json
- synthetic_seed.json
- historical_environment/
- official_documents/
